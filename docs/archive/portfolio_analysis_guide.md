# Portfolio Analysis Guide

This guide documents the **Portfolio Analysis Standalone** tool, which is used to evaluate and compare different capital allocation strategies on top of Walk-Forward Optimization (WFO) results.

## Overview

While the WFO pipeline optimizes parameters for each coin, the **Portfolio Analysis** phase determines how to best distribute capital among those signals. The current default is a flat percentage (e.g., 10%) per trade, but this standalone tool allows you to "compete" different strategies to find the best risk/reward balance.

The tool currently compares:

1. **Flat Percentage (Baseline)**: The standard 10% per position approach.
2. **Max Diversified (1/N)**: Splits capital equally among all symbols in the pool, ensuring every signal is taken.
3. **Volatility Weighted**: Allocates more capital to low-volatility assets and less to high-volatility ones (Inverse Volatility).
4. **Robustness Weighted**: Allocates capital proportional to the WFO "Robustness Score" (favoring strategies that generalized better across folds).
5. **Buy & Hold (EW)**: An equal-weight buy-and-hold benchmark for absolute comparison.

## Quick Start

To run the analysis on a completed WFO run:

```bash
python scripts/portfolio_analysis_standalone.py --results-dir results/run_wfo_per_coin_multi_strategy_YYYYMMDD_HHMMSS
```

## Comparison Metrics

The tool generates a "Competition Table" with the following metrics:
- **Total Return [%]**: Aggregate portfolio growth.
- **Sharpe Ratio**: Risk-adjusted return (using daily volatility).
- **Sortino Ratio**: Risk-adjusted return focusing on downside volatility.
- **Max Drawdown [%]**: Maximum peak-to-trough decline.
- **Win Rate [%]**: Percentage of profitable trades.
- **Profit Factor**: Gross profit / Gross loss.
- **Expectancy**: Average profit per trade.
- **Total Trades**: Number of trades executed.

## Interpreting Results

### Volatility Weighted vs. Flat 10%

In most crypto markets, **Volatility Weighting** significantly reduces the Maximum Drawdown (sometimes by 50% or more) while maintaining a comparable Sharpe Ratio. This makes it ideal for users sensitive to large dips.

### Max Diversified (1/N)

Use this strategy if you want to ensure that *every* signal generated by the WFO-optimized parameters is executed. The flat 10% approach may skip signals if 10 positions are already open, whereas 1/N scales the position size to fit the entire pool.

## Outputs

All results are saved in a sub-directory of the run: `results/YOUR_RUN/portfolio_analysis/`

- **`comparison_stats.csv`**: A CSV table of all strategy metrics.
- **`equity_comparison.html`**: Interactive Plotly chart comparing the equity curves.
- **`drawdown_comparison.html`**: Interactive Plotly chart comparing the drawdown profiles.

## Adding New Strategies

To add a new strategy, implement a new function in `scripts/portfolio_analysis_standalone.py` that returns a `vbt.Portfolio` object and register it in the `main()` function's competition loop.

Example:

```python
def run_strategy_custom(close, entries, exits, config):
    # Your custom sizing logic here
    return vbt.Portfolio.from_signals(..., size=my_custom_array)
```
