## Finish line and boundaries

Completion means both signals have final registered artifacts and supported
verdicts. It does not mean every unknown has been eliminated or that either
strategy passes. A final UNRESOLVED verdict is legitimate; calling the audit
complete while its registered completion conditions are unmet is not.

The report must answer: which exact source representation was tested, which
annual requirements passed/failed/remained unknown, whether any five consecutive
complete years qualify, what external inputs remain, and whether Phase 2 may begin.
Separate original insider timing, the approved date-only representation and PEAD.

- No returns, prices/EPS values, P&L, backtests, new detectors or production changes.
  Metadata, identifiers, shares for lot reconciliation, timestamps and flags only.
- Use the working read-only connector; no `.env`, DB writes or schema-ensuring
  loaders. Do not ask the owner to configure an access path we already possess.
- No purchases, trials, accounts, outreach or new vendor routes. Preserve R1–R9.
- Preserve A6/A7/A9, all 136 insider checkpoints, failed selections, quarantines,
  right censoring and separate denominators. No NOC one-day tolerance.
- Latest collection parent: `insider-predecessor-bnz1mn22`, 82 SEC, zero Yahoo,
  105.33867007261142 seconds. Verify actual state before later work; inherit it
  without double-counting copied prefixes. All prior claims remain consumed.
- SEC ≤5/sec, initial plus three counted retries, ≤20,000 SEC / ≤2,000 Yahoo,
  six-hour cumulative runtime; stop at first new 403/429, no automatic restart.
  Planning does not authorize fresh collection. Exact dependent work needs a
  reviewed acquisition package and existing authority/stop clearance.
- Vendor-search spent/remaining time is unknown under the two-hour ceiling.
  Reconcile existing receipts first. If unrecoverable, record that blocker and
  make no new search; do not invent a remaining allowance or exclude silent routes.

## Review focus

Do not turn operational examples into population coverage; a stored mapping into
a verified historical interval; a positive flag list into exhaustive screening;
a corrected lot into an entire filing replacement; or a readiness NO-GO into a
strategy-performance or universal-source NO-GO.

## Exhaustive completion checklist and ownership

This is the single completion plan for the registered audit, including acquisition
dependencies and publication. Codex owns every task and verifies delegated output.
Flash receives only one specified extraction/link check at a time, with exact
input paths and literal, checkable output; it does not write plans, code or verdicts.

Before closing Task 1, cross-reference every P1–P4, I1–I4 and A1–A12 requirement
against the existing runner's requirement matrix. Each entry must name its owner,
source/hash, producing task, verification and outstanding dependency. Preserve
existing fields rather than introducing a second competing audit schema.

A missing input is an open dependency, not a resolved deliverable. For each such
dependency Codex must identify the exact field/export, source and scope, whether
it can be recovered within current authority, and the bounded action needed to
obtain it. Perform authorized recovery; if unavailable or outside authority,
carry the exact dependency into the final disposition. An evidence-based
UNVERIFIED predicate can be final only after the registered bounded audit actually
completes; mandatory execution inputs still block canonical publication.

The first Flash assignment is a literal key/line extraction from
`validate_evidence_record()` and `reviewed_fields()` in the existing audit modules.
Codex checks it against source before using it in Task 1. Later suitable jobs are
exact hash/link checks or extracting a named field from an identified cached file.

Execution follows Tasks 1–5 without another planning cycle. Tasks 2–4 may proceed
independently after their input contracts are frozen. No automatic repeat vendor
survey, collection restart or review loop. Final review findings are verified and
fixed; any remaining substantive objection prevents a clean-completion claim.
