Test the published Open Source Asset Pricing `PS` portfolio `10`, whose reported average score is highest or tied for highest in all observed months and whose reported short count is zero. The score combines nine accounting indicators within high book-to-market stocks. It overlaps the closed value and profitability families; this separate question preserves those NO-GOs. **Pre-run review correction:** this is the provider's score as implemented, not a canonical Piotroski F-score. Five of its nine components can award a point when a prior value is missing or a denominator is zero; its margin component uses the same earnings figure in both ratios. How often this affects the portfolio is unknown. The value-weighted portfolio is rebalanced monthly; tied integer scores mean the highest available group can include stocks with a score below 8. Its initial 1972 months contain as few as four stocks. The mapping and counts were checked without examining returns.

Compare against French broad-market total return (`Mkt-RF + RF`, not SPY) over January 1972–December 2025 and January 1994–December 2025. The first window starts with the portfolio's reported history and ends with the provider release; neither is unseen data. Use the frozen provider file SHA-256 `76599d94beab94cc8973d8a126e8efbed98ee79f677738c55b2389f17387ba96` and French market archive SHA-256 `b03d39e4bb253dda0f14893db3b78e64b40b8d6549a0fc0fd4111dae84c98618`. The data have different publication vintages. The [driver](code/ps_score_screen.py) checks both; `--check-only` does not open return columns. A new file requires a new pre-run amendment.

The full-window gate is 12-lag Newey–West t ≥ 3 and one-sided p ≤ 0.00135 after an assumed 1% annual candidate cost. The since-1994 gate requires annualized compound growth at least 1 percentage point above the market after that cost. Both must pass. Report a 2% cost stress, terminal wealth and month-end maximum drawdown. Costs are unmeasured and pretax. Missing months, non-finite observations or sentinel values stop the calculation and leave the result unresolved. Do not change the portfolio, windows, benchmark or costs after viewing results. The single-test threshold does not correct for earlier screens.

Also report the same fixed windows against the previously frozen French `BIG HiBM` portfolio, SHA-256 `82b66ccd6a4dff103eba51b60e1f2310eaa94bbebbb843550173b972c64cdbff`, as a **descriptive** value comparison. Apply the same candidate-only cost assumptions; it is not an additional pass gate or a matched universe. It uses a different value breakpoint, size definition and data vintage, so it cannot isolate the effect of the accounting score. No other comparison or new gate is authorized by this proposal.
