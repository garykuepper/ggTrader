# Task 49 generator checkpoint

`tests/paper/equivalence/generator.py` provides `Case` and locally seeded `build_case`. It samples the requested modes and sizing, stops, sweep, holdings and signals, risk inputs, broker and environment untradability, pending orders, split and dividend evidence, fill sequences, submit, notifier and clock failures, stale/late gates, and lock and membership failure metadata. Buys are unique within each sleeve; only deliberate duplicate-buy scenarios share a candidate across sleeves. Persistence defaults come from the existing scenario fixture.

The three late planner cases and duplicate-buy case are constructed so that random earlier gates do not mask them. In seeds 0–599 there are 16 late-stop, 23 late-exit, 14 late-sleeve and 25 duplicate-buy cases; the targeted tests run every one and confirm the former reach an order and then raise `KeyError`, and the latter submit the same symbol twice. There are 67 membership-failure inputs; their actual injection and reachability require the later recording runner.

The tests compare all 600 cases in subprocesses with Python hash seeds 1 and 2, check positive sizing and uniqueness across 600, and run all 600 scenarios through the existing harness without a harness error.
